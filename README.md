# Low Tide© — Drop 01

Storefront for **Low Tide©**, a limited streetwear brand from Cebu, PH.
*Only when the water's out.*

A static, responsive single-page site (HTML, CSS and vanilla JS, no build step):

- Animated hero with the red horse campaign image
- Scrolling brand ticker with the horse mark
- Drop 01 catalog with reveal, float, 3D tilt and quick-add animations
- Tee/Hoodie filters and sorting
- Product pages with an image slider, size selector and a sticky mobile add-to-cart bar
- Cart drawer, lookbook and newsletter sections

> Checkout is a demo: the cart runs in the browser. Connect Shopify (Buy Button or a Shopify theme) to take real orders.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Import this repository in Vercel as a static site. There's nothing to build and no settings to change.
